📌 Complete System Workflow
1. Student submits outpass.
2. Parent receives OTP by email.
3. Parent/student verifies the OTP.
4. Parent approval is recorded.
5. Mentor reviews the request.
6. Mentor approves or rejects the request.
7. Approved outpass becomes available for security verification.
8. Security scans the student's QR code.
9. Actual exit time is recorded.
10. Student leaves the campus.
11. Student returns to campus.
12. Security scans the QR code again.
13. Actual return time is recorded.
14. Outpass is completed and stored in student history.
15. Relevant email notifications are recorded in the notification system.

Admin: Monitors and manages the complete system.

Live Database Dashboard: Statistics and activity are loaded from the Flask backend and MySQL database. No student, parent, mentor, security or outpass values are hardcoded in this page.
